# KREIS Assessment - Complete Application Mockup (3998 characters)

```
Create a complete UI/UX design mockup set for "KREIS Assessment" - a modern educational assessment platform showing all key screens in a professional presentation layout.

APPLICATION OVERVIEW:
Educational platform for managing tests, viewing results, and analytics across institutes, principals (branches), and students with role-based dashboards.

DESIGN SYSTEM:
Colors: Primary Blue #1890ff, Success Green #52c41a, Warning Yellow #faad14, Error Red #ff4d4f, Background #f0f2f5, White cards
Typography: -apple-system, BlinkMacSystemFont, Segoe UI, Roboto. Headings bold 24-30px, body 14px
Components: Rounded corners 12px, shadows 0 1px 2px rgba(0,0,0,0.03), spacing 24px between sections, 16px between cards
Style: Modern, clean, professional, Ant Design inspired, high-fidelity mockups

SCREEN 1 - LOGIN (top-left):
Gradient purple background (#667eea to #764ba2). Centered white card (450px) with rounded 16px corners, elevated shadow. Large "K" logo in gradient rounded square (80px) at top. "KREIS Assessment" title bold 32px. "Sign in to your account" subtitle gray. Two inputs: Username and Password with icons (user, lock), 48px height, rounded 8px. Blue gradient "Sign In" button full width, 48px height. Footer text "© 2024 KREIS Assessment" small gray.

SCREEN 2 - MAIN DASHBOARD (top-center):
Fixed dark sidebar (200px, #001529) with "KREIS" logo and menu items (Dashboard selected blue, Results, Tests). White header bar (64px) with "Dashboard" title, notification bell, user avatar dropdown. Light gray background (#f0f2f5). Filter section: white card with 4 dropdowns (Institute, Category, Test disabled until category selected, View By). Four statistics cards in row: Total Submissions (green, 156, user icon), Average Score (blue, 67.5%, trophy icon), Highest Score (green, 98.5%, up arrow), Lowest Score (red, 23.0%, down arrow). Each card has colored circular icon (56px), large number, label, trend indicator. Below: Two charts side-by-side - Score Distribution pie chart (5 colored segments) and Branch-wise Performance horizontal bar chart (green bars). Bottom: Top Performers list with horizontal bars.

SCREEN 3 - TEST RESULTS (top-right):
Same sidebar/header. Page title "Test Results" with "Download Excel" blue button top-right. Filter card with 6 dropdowns (Institute, Category, Test, Search, Principal, Branch). Modern data table with columns: Student Name (with avatar), Batch, Principal, Scored Marks, Total Marks, Percentage (color-coded with progress bar: green ≥60%, yellow 40-60%, red <40%), Correct (green), Incorrect (red), Skipped (gray), Submitted At, Action (blue eye icon). Expandable rows show subject-wise breakdown with nested tables showing question details. Pagination at bottom "1-10 of 156".

SCREEN 4 - STUDENT DASHBOARD (middle-left):
Student info banner: gradient card with large avatar (80px), name "John Doe" bold 24px, class/batch info. Filter section: Category and Test dropdowns. Four performance cards: Scored Marks (45/100, blue trophy), Percentage (45%, color-coded), Correct Answers (15/40, green checkmark), Accuracy (37.5%, target icon). Question Analysis donut chart (Correct green 37.5%, Incorrect red 25%, Skipped gray 37.5%). Subject-wise Performance horizontal bars showing 4 subjects with percentages and color coding. Strengths card (light green background) listing topics with high accuracy. Areas to Improve card (light red background) with low-scoring topics.

Quick action buttons row: Create Test, Assign Test, View Results, Manage Batches, Reports. Performance cards similar to main dashboard but branch-focused. Batch Comparison grouped bar chart showing multiple batches with 3 subjects per batch (blue, green, orange bars). Batch cards grid (3 columns) showing batch name, student count, active tests, average score, teacher assigned. Recent Activity timeline with colored dots and timestamps.

SCREEN 6 - TEST MANAGEMENT (middle-right):
"Test Management" title with "Create New Test" blue button top-right. Search bar (400px) on left. Filter panel: collapsible white card with 2 rows of filters (Search, Category, Institute, Principal, Status, Batch multi-select, Date Range, Created By). Tests table with columns: Test Name (with icon), Category (blue tag), Institute, Duration (60 min), Total Marks, Questions count, Status (green "Active" tag or gray "Inactive"), Created Date, Actions (4 icon buttons: view eye, edit pencil, duplicate copy, delete trash - all blue except red delete). Pagination showing "1-10 of 156 tests".

SCREEN 7 - CREATE TEST MODAL (bottom-left, overlay):
Large modal (1000px width) with rounded 16px corners. Header: "Create New Test" title with close X. Progress steps indicator: Step 1 Basic Info (active blue), Step 2 Test Pattern, Step 3 Questions, Step 4 Settings (all connected with lines). Form showing Step 1: Test Name input, Category radio buttons with icons (Full Length, Monthly, Chapter Wise), Institute dropdown, Test Pattern dropdown, Description textarea, Duration number input, Total Marks (auto-calculated). Footer: Cancel button (gray), step indicator "Step 1 of 4", Previous and Next buttons (blue).

SCREEN 8 - QUESTION DETAIL MODAL (bottom-center):
Modal (900px) showing question details. Header: "Question Details" with question number "15 of 40", navigation arrows, close X. Question section: gray box with question text and math notation. Four option boxes (A, B, C, D) - student's answer has orange border, correct answer has green border. Answer comparison: two columns showing "Your Answer" (red background if wrong) and "Correct Answer" (blue background). Solution section: light blue collapsible box with step-by-step explanation. Metadata cards: Status (Correct/Incorrect with icon), Marks (1/2), Time (45s), Difficulty (Medium). Analytics: mini pie chart showing class performance, time distribution bar chart. Footer: progress bar, "Mark for Review" toggle, Previous/Next buttons.

Smartphone frame showing mobile responsive design. Hamburger menu icon top-left, "KREIS" logo center, notification bell and avatar top-right. Collapsible filter accordion. Statistics cards stacked vertically (full width). Charts optimized for mobile width. Table with horizontal scroll. Bottom navigation bar with 4 icons: Dashboard, Results, Tests, More. Touch-friendly 44px minimum tap targets.

Arrange all 9 screens in 3x3 grid on light gray background with subtle shadows between screens. Each screen labeled below with screen name. Professional presentation style showing complete application flow. Consistent design language across all screens. Modern, clean, organized layout demonstrating full platform capabilities.

- Icons: outlined style, consistent sizing
- Responsive grid layouts
- Professional spacing and alignment
```
